# Golden Rewards — مشروع Flutter متكامل

تطبيق مهام واستبيانات وألعاب نقاط عربي متجاوب مع نظام مكافآت، صفحة سحب، ولوحة أدمن مخفية بنقطة (`.`) محمية بكلمة مرور وتقارير إحصائية كاملة.

## خطوات البناء التلقائي على GitHub (APK + Web)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد إليه بالكامل (بما في ذلك مجلد `.github/workflows`).
2. انتقل إلى تبويب **Actions** في مستودعك على GitHub.
3. سيبدأ سير العمل **Build Flutter APK & Web** تلقائيًا بتثبيت المكتبات وبناء ملف `app-release.apk`.
4. بعد انتهاء البناء، افتح آخر Run وانزل لأسفل إلى قسم **Artifacts** لتحميل `golden-rewards-apk`.

## بيانات الدخول للوحة الإدارة
- **الزر المخفي**: النقطة (`.`) الموجودة بجانب كلمة **الرئيسية** في الشريط العلوي.
- **كلمة المرور الافتراضية**: `admin2026`
